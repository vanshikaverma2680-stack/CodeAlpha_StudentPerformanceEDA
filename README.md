# CodeAlpha_StudentPerformanceEDA
Exploratory Data Analysis of student academic performance using Python, Pandas, Matplotlib and Seaborn.
# Student Academic Performance — Exploratory Data Analysis

**Internship:** CodeAlpha Data Analytics Internship
**Task:** Exploratory Data Analysis (EDA)

## Project Overview

This project explores student academic performance using Python. It investigates relationships between study time, absences, previous academic failures and final mathematics grades.

## Objectives

* Understand the structure and quality of a real-world dataset.
* Examine missing values, duplicate records and potential outliers.
* Calculate descriptive statistics.
* Visualize patterns in study time, absences and academic grades.
* Investigate correlations and selected statistical hypotheses.

## Dataset

The project uses the Student Performance dataset from the UCI Machine Learning Repository.

Source: https://archive.ics.uci.edu/dataset/320/student+performance

The analysis focuses on mathematics performance. The dataset includes student characteristics, study-related information, absences, previous failures and grades.

## Tools and Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* SciPy
* Google Colab

## Methodology

1. Load and inspect the dataset.
2. Examine data types and descriptive statistics.
3. Check missing values, duplicates and potential anomalies.
4. Compare final grades across study-time and previous-failure categories.
5. Explore absences and grades using visualizations.
6. Investigate associations using Spearman correlation.
7. Examine numerical relationships with a correlation heatmap.

## Project Files

* `CodeAlpha_Task2_StudentPerformance_EDA.ipynb` — Analysis notebook containing code, explanations and results.
* `student_performance_data.csv` — Dataset used in the analysis.
* `correlation_heatmap.png` — Visualization of correlations among numerical variables.

## Results

The notebook contains descriptive statistics, visualizations and statistical tests used to investigate the research questions. Specific findings should be interpreted from the executed notebook outputs.

## Limitations

The analysis focuses on mathematics performance in the available dataset. Correlations indicate associations rather than causation, and unusual observations are not necessarily data errors.

## Conclusion

This project demonstrates exploratory data analysis using Python, including data inspection, quality checks, descriptive statistics, visualization and correlation analysis.
